# 도면부호 및 구성요소 대응표

| 도면부호 | 구성요소 | 주요 기능 |
|---:|---|---|
| 100 | 다중 도구 실행계획 보완 시스템 | 본 발명의 전체 오케스트레이션/보완 시스템 |
| 110 | 사용자 요청 인터페이스 | 사용자 또는 상위 시스템의 작업 요청 수신 |
| 120 | 실행계획 생성부 | 도구 정보에 기초하여 초기 실행계획 생성 |
| 130 | 도구 정보 관리부 | 도구 명세, 실제 조건정보 및 요구 조건정보 관리 |
| 131 | 실제 조건정보 | 선행 도구 출력 데이터의 실제 실행조건 메타데이터 |
| 132 | 요구 조건정보 | 후속 도구 입력이 요구하는 실행조건 메타데이터 |
| 140 | 의존관계 분석부 | 선행-후속 도구 간 데이터 전달 의존관계 추출 |
| 150 | 실행조건 평가부 | 실제 조건과 요구 조건 비교 및 결손도 산출 |
| 151 | 실행조건 결손도 벡터 | 조건별 위반 정도를 나타내는 벡터 |
| 160 | 위험도 산정부 | 의존관계 위험도 및 계획 위험도 산출 |
| 161 | 의존관계 위험도 | 하나의 데이터 전달 의존관계에 대한 위험도 |
| 162 | 실행계획 위험도 | 실행계획 전체에 대한 위험도 |
| 170 | 보완 결정부 | 위험도 기준값과 비교하여 보완 수행 여부 결정 |
| 180 | 보완 후보 생성부 | 위반조건에 대응하는 보완 도구/후보 계획 생성 |
| 181 | 위반조건 식별정보 | 위험도에 기여한 실행조건 식별 결과 |
| 182 | 보완 후보 집합 | 적용 가능한 하나 이상의 보완 후보 |
| 190 | 보완 최적화부 | 잔여 위험도 및 실행비용에 기초한 후보 선택 |
| 191 | 잔여 위험도 | 보완 후보 적용 후 남는 계획 위험도 |
| 192 | 실행비용 | 추가 지연, 호출 수, 자원비용 등 |
| 193 | 후보 목적값 | 잔여 위험도와 비용을 결합한 후보 평가값 |
| 200 | 실행계획 갱신 및 재검증부 | 선택 후보 삽입 후 실행조건 및 위험도 재검증 |
| 210 | 도구 실행부 | 확정된 실행계획에 따른 외부 도구 호출 수행 |
| 220 | 외부 도구 호출 클라이언트 | MCP 또는 기타 도구 호출 프로토콜 클라이언트 |
| 230 | 외부 도구 서버 | 복수의 외부 도구를 제공하는 서버/서비스 |

## 실행조건 기호

| 기호 | 의미 |
|---|---|
| τ | 스키마 유형 |
| s | 의미 유형 |
| u | 단위 |
| r | 기준좌표계 |
| t | 최신성 |
| q | 신뢰도 |
| p | 출처 |
| d(i,j,k) | 의존관계 (i,j)의 k번째 실행조건 결손도 |
| R(i,j) | 의존관계 위험도 |
| R(W) | 실행계획 위험도 |
| θ | 보완 판단 위험도 기준값 |
| C(r) | 보완 후보 r의 실행비용 |
| λ | 비용 반영계수 |
| J(r) | 보완 후보 목적값 |
